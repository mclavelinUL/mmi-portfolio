# Plugin pour la gestion du portfolio en BUT MMI

Ce plugin nécessite l'ajout d'ACF Pro dans le dossier vendor (vendor/advanced-custom-fields-pro)

## Installation

1. Passez par le menu Extensions -> Ajouter une extension -> Téléverser une extension
2. Téléverser le fichier zip
3. Activer l'extension
4. Ajouter un lien personnalisé dans votre menu: http[s]://votreurl.ext/portfolio-pedagogique/realisation-mmi/
